# Business Analytics Database

## Overview

This project demonstrates the use of PostgreSQL, SQL, and Python to analyze business operations using the Northwind sample database. The project explores customer behavior, sales performance, employee activity, and product trends through relational database queries and analytical workflows.

## Business Problem

Organizations rely on transactional databases to understand customer purchasing behavior, product performance, and sales trends.

The objective of this project was to query and analyze a normalized relational database to generate business insights that support operational and strategic decision-making.

## Objectives

- Query data from a PostgreSQL database
- Analyze customer and sales performance
- Perform multi-table SQL joins
- Create reusable SQL views
- Demonstrate relational database concepts

## Dataset

This project uses the Northwind sample database, a widely used relational database containing information about customers, employees, suppliers, products, orders, and order details.

## Database Tables

The project analyzes data from multiple related tables, including:

- Customers
- Orders
- Order Details
- Products
- Categories
- Employees
- Suppliers
- Shippers

## Example Business Questions

- Which customers generate the highest revenue?
- Which products contribute the most to sales?

## Key Insights

- Multi-table joins enable comprehensive business analysis across transactional datasets.
- SQL views simplify repeated analytical queries.
- Relational databases support efficient analysis of customer, sales, and product performance.
